# V30 — Resume without losing the evidence

**Recording brief only; unreleased source features, no video produced.**
Audience: experienced developers. Companion: [L30](../lessons/L30-evidence-continuation.md).

1. **Open with the user problem (30 seconds).** "Yesterday's task crossed two
   projects. Today we need the constraint and the next question—not a dump of
   every conversation." Show two disposable terminals and a fixed source pin.
2. **Evidence, not apparent confidence (2 minutes).** Type `wiki-evidence plan`,
   pause on the page/source digest and full negated constraint, inspect the plan,
   then apply its exact digest. Change a source; show the affected-page warning.
   Explain that a quotation check is not a truth detector.
3. **A continuation is an offer (2 minutes).** Create a small labelled packet.
   Show from the other cwd in a fresh process, then show again. It is not
   consumed and it never runs the next-step text. Zoom on project bindings,
   hypothesis status, stale evidence and whole-entry truncation.
4. **Consolidate deliberately (3 minutes).** Inspect two synthetic stored sessions,
   prepare structured evidence and exact literals, create a proposal without an
   extra model call, and inspect before apply. Show a changed-source refusal
   and unchanged target memory. Explain history retention and no automatic deletion.
5. **Close (30 seconds).** Show the real offline contract output and disclose
   synthetic scope. No claim of human rehearsal, cross-model gains or fleet
   deployment. Do not show private paths, actual infrastructure or credentials.

Use deliberate pauses after digest comparisons and failure output. Keep commands
visible long enough to read; use real disposable command output, not fabricated
results. Source-only availability must remain visible until a verified release.
