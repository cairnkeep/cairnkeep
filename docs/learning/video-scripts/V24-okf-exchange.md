# V24 - Reviewed knowledge exchange

**Companion lesson:** [L24](../lessons/L24-okf-exchange.md)
**Target length:** 9 minutes

## Recording outline

1. State the boundary: OKF is portable context exchange, not a second memory
   owner, agent loop, trust authority, or background sync service.
2. Show a two-concept synthetic OKF 0.2 directory and run
   `cairn pack validate-okf`.
3. Import it with an ID, semantic version, and license; point out that the
   source directory remains unchanged and the pack digest is authoritative.
4. Enable the digest for one disposable project. Show structured `okf`
   provenance in list/search/read and traverse one local link with
   `context_pack_related`.
5. Break a link and make a concept stale in a second fixture. Show diagnostics
   without implying that Cairnkeep verified the source claims.
6. Select one project Markdown file, run `export-okf --check`, and emphasize
   that no output exists. Inspect the allowlist, redaction count, and digests.
7. Apply with the exact preview digest and validate the result. Demonstrate one
   rejected private path and one mismatched confirmation.
8. Close with the external-adapter gate: demand a measured, otherwise
   impossible workflow before accepting another network and data owner.

## Recording cautions

- Use only synthetic paths, content, sources, and credentials.
- Keep embeddings disabled so the recording proves the offline fallback.
- Do not claim publisher authenticity, semantic correctness, or quality gains.
- Remove the disposable pack object and project pointer on camera.
