# Evidence and Evaluation Track

**Audience:** maintainers and advanced practitioners evaluating optional layers
**Prerequisite:** Practitioner track
**Total time:** about 4 hours
**Infrastructure:** local fixtures first; a live harness is operator-provided

1. [L13 - Session evidence and hindsight](../lessons/L13-session-evidence.md)
2. [L14 - Typed memory and controlled import](../lessons/L14-typed-memory.md)
3. [L15 - Capability governance](../lessons/L15-capability-governance.md)
4. [L16 - Evaluation and ablation](../lessons/L16-evaluation.md)
5. [L17 - The agent boundary](../lessons/L17-agent-boundary.md)
6. [L19 - Validated skill improvement](../lessons/L19-validated-skill-improvement.md)
7. [L26 - Context intelligence with explicit authority](../lessons/L26-context-intelligence.md)

The track is complete when the learner can explain each consent boundary,
inspect and manage every local evidence store, including Git-linked work
evidence, compare baseline and ablation
reports without making unsupported claims, apply or roll back an exact eligible
skill proposal, and distinguish that narrow runtime from the design-only
general meta-agent contract.

L16 also covers the offline memory protocol controls: distinguish direct tool
events from narration and explain why protocol observations, caller-asserted
consent and task-quality evidence are separate claims.

Optional 2.28 supplement:
[joint continuity evidence](../../memory-continuity-workflow.md). Inspect actual
map/related/exact-read/search/inspection calls, the independently enumerated
Markdown policy, development-only votes and eight held-out query cases per arm.
Separate freshness warnings and curated linked coverage from ordinary retrieval
quality; disclose operator work, per-call/summed bytes and different transport
overhead. Keep the no-gain ranking result, negative controls and failed original
SDK proposal visible. This is not an independent human pilot or a video recording.

Hands-on spine: `course-05-evidence` through `course-07-evaluation` in the
public [course labs](https://github.com/cairnkeep/cairnkeep-course-labs).
