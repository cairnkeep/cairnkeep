# L30 — Evidence-bound continuity

**Status:** Brief — unreleased source-checkout supplement, not recorded.
Prerequisites: L04, L07, L13 and L26. Suggested lab time: 35 minutes.

## Outcome

Continue one task across two projects and independent processes without losing
an exact network constraint, treating a hypothesis as truth or consuming another
session's context. No real host names, credentials or production stores.

## Exercise

1. Build the source checkout. Run `npm --prefix mcp-memory-server run check:evidence-continuation`.
2. Follow [the explicit manifest example](../../evidence-continuity.md) in a disposable
   project. Inspect a no-write plan and publish only its exact digest.
3. Change the cited source without changing the wiki. Check the old digest:
   identify `source_changed`, its affected page and any missing quotation.
4. Create a packet covering two disposable projects, with a supported decision,
   a failed approach, an open question and an unconfirmed next step. Read its
   exact digest from both cwds and two fresh processes. It remains readable.
5. Lower the output budget. Show whole-entry omission and the truncation count;
   do not shorten `Do NOT expose port 8080.` into a misleading fragment.
6. Use two explicitly captured synthetic trajectories to prepare consolidation
   candidates. Include complete literal requirements and a hypothesis label.
   Proposal creation is not promotion; inspect before exact-digest apply.
7. Change one trajectory before apply and demonstrate refusal without target
   writes. Recreate a current proposal rather than bypassing the source check.

## Acceptance criteria

- Distinguish source integrity, quotation presence, factual correctness and approval.
- Explain why reading a packet neither claims a task nor executes next steps.
- Demonstrate that hypothesis status survives ordinary-memory promotion.
- Explain explicit project selection, output limits, retained originals and
  separate private backup needs.
- Report protocol behavior and context costs, not a model-quality victory.

This lab does not enable production features, revise any earlier lesson's
readiness, or require a new subscription, local inference service or recording.
